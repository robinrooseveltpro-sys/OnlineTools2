What does robots.txt do?

A robots.txt file publishes crawl instructions for compliant web crawlers. For example, it can request that a crawler avoid a particular directory. It is normally available at the root of a hostname, such as https://example.com/robots.txt.

Each hostname has its own robots.txt location. A file on one subdomain does not automatically establish the rules for another subdomain.

Understanding the main directives

  • User-agent: identifies the crawler group to which the following rules apply.
  • Disallow: specifies a path that the matching crawler should not crawl.
  • Allow: specifies a path that may be crawled. Supported crawlers can use it to allow a more specific path within a disallowed directory.
  • Sitemap: provides the absolute URL of a sitemap file. It is not limited to a particular user-agent group.
  • Comments: begin with a hash symbol (#). The content after that symbol is treated as a comment.

Examples of robots.txt rules

Allow crawling by default

User-agent: *
Disallow:

An empty Disallow value indicates that no paths are disallowed by that rule. This is an explicit allow-by-default starting point.

Disallow a directory

User-agent: *
Disallow: /private/

This requests that matching crawlers avoid paths beginning with /private/. It does not secure that directory against people or unauthorized access.

Provide a sitemap reference

User-agent: *
Disallow:

Sitemap: https://example.com/sitemap.xml

Replace the example address with the actual absolute URL of your sitemap.

Important robots.txt mistakes

  • Accidentally publishing Disallow: / can block crawling across the matching group. Check this rule particularly carefully before publishing a production website.
  • Putting directives before a User-agent group can cause them to be ignored or interpreted differently than intended.
  • Using a relative URL in a Sitemap directive is incorrect; use an absolute URL with a valid scheme and hostname.
  • Assuming that robots.txt prevents indexing is a mistake. A URL can sometimes appear in search results without its page being crawled.
  • Adding Crawl-delay does not control Google's crawling because Google does not support that directive.

Frequently asked questions

Will this tool test my live website?

No. It validates the file text entered in the editor. It does not fetch a live robots.txt file, check HTTP responses, or emulate every crawler's full matching algorithm.

Can I block a private page with robots.txt?

Do not rely on it for privacy or security. Use authentication, authorization or another appropriate access-control method for confidential content.

Does a valid robots.txt guarantee SEO improvement?

No. The file helps communicate crawl preferences. Its effect depends on the site, the directives used, and the crawler following those rules.

Can I put multiple user-agent groups in one file?

Yes. A robots.txt file may contain several groups, each associated with one or more crawler product tokens and their rules. Review duplicate and overlapping groups carefully.
