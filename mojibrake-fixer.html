What is mojibake?

Mojibake is garbled text that appears when characters are decoded using an incorrect character encoding. A text file may contain bytes representing one character, but an application can interpret those bytes using another encoding and display the wrong symbols. The result can include strange sequences such as Ã©, â€™, or FranÃ§ais. Unicode describes these symptoms as possible encoding problems. Read Unicode's explanation of display problems.

This online mojibake fixer looks for common, reversible patterns. It can often repair text that was UTF-8 encoded and later incorrectly interpreted as Windows-1252 or a similar legacy single-byte encoding. It also offers separate tools for common text representations such as HTML entities and escaped Unicode.

Why does UTF-8 text become garbled?

UTF-8 read as Windows-1252 or Latin-1

UTF-8 represents many characters using multiple bytes. If a program reads those bytes with a different encoding, one character can appear as several unrelated symbols. For instance, an accented character can turn into a visible sequence beginning with Ã.

A mojibake fixer can often reverse this pattern when the intermediate characters still represent the original bytes. Browser encoding APIs support UTF-8 and multiple legacy encodings, including Windows-1252. See the browser encoding reference.

Double encoding or repeated decoding mistakes

Some text passes through the same incorrect conversion more than once. That may produce sequences that still look wrong after one repair. Repeated passes can help with some of these patterns, but each extra transformation introduces more uncertainty. Compare the available candidates instead of applying endless passes.

HTML entities are not the same as mojibake

Strings such as &copy; or &#233; are character references. They are not necessarily encoding errors. Use the HTML entity decoding option when your text literally contains these references and you want the corresponding characters displayed.

URL percent escapes and Unicode escapes

A string like %C3%A9 contains percent-encoded bytes. A string like \u00E9 contains a backslash escape commonly used in JSON or JavaScript. Choose the appropriate transformation for the input you have; do not assume every sequence of special characters is mojibake.

Can every garbled character be repaired?

No. If a program merely interpreted the original bytes using the wrong encoding, the original information may still be recoverable. However, if an application replaced unsupported characters with question marks or replacement symbols and then saved the damaged result, the original characters may no longer be present.

For example, a literal question mark may be original punctuation, or it may be the only remaining trace of a lost character. No automatic fixer can reliably reconstruct the missing information without another source or context.

Likewise, not every unusual sequence is corrupted. Accented characters, multilingual text, emoji, mathematical symbols, source code, and technical strings can be valid as written. The heuristic ranking used by this tool is a clue, not a definitive language or correctness detector.

Frequently asked questions

What does a mojibake fixer do?

A mojibake fixer tries to restore text that became garbled when bytes were interpreted using the wrong character encoding. This page generates alternative repairs for common patterns and lets you compare the results.

Is this mojibake fixer free?

Yes. You can use its text repair methods, inspect alternative candidates, copy the result, and download repaired text without creating an account.

Does it repair UTF-8 encoding errors?

It can often reverse recognizable UTF-8 mojibake when the intermediate text preserves the necessary characters. It cannot restore information that has already been discarded or replaced.

Can it repair text that is double encoded?

The tool tries repeated repair passes and displays different candidates. Some double-encoded strings can be recovered, but not every multi-stage conversion is reversible or unambiguous.

Does the tool support HTML entities and URL encoding?

Yes. Separate controls let you decode common HTML named and numeric entities, percent-encoded URL text, and common JavaScript-style Unicode or hexadecimal escapes.

Are my files uploaded to a server?

The file reader and repair functions on this page process the text locally in your browser. The repair code does not send the text to a validation API. Do not treat this statement as a guarantee about other scripts or services installed on a modified copy of the page.

Can the fixer recover question marks or replacement characters?

Not reliably. If the original character was replaced with a question mark or replacement symbol and the original byte information was discarded, the missing character cannot usually be reconstructed from that symbol alone.

Why are there multiple repair candidates?

An encoding mistake can have more than one plausible interpretation. Candidates allow you to compare repair strategies rather than accepting an automatic guess without reviewing it.

Is the highest heuristic score guaranteed to be correct?

No. The ranking looks for common encoding artifacts and suspicious characters. It does not understand every language, domain-specific word, or meaning. Inspect the output and compare it with a trusted source before using it.

Can it repair every language?

It can attempt common encoding repairs across text containing many languages, but the results depend on the original encoding and damage. Some characters and mixed-encoding cases may not have a reliable automatic fix.
