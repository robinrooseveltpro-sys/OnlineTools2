What is mojibake?

Mojibake is garbled text produced when bytes are decoded using the wrong character encoding. For example, the word café may appear as CafÃ© after UTF-8 bytes are interpreted using a different character table.

UTF-8 encodes many characters with multiple bytes. If each of those bytes is treated as a separate character, the resulting text can look like random symbols, incorrect punctuation or extra accented letters.

Why multiple repair candidates matter

Character encodings are not always recoverable by guessing. Some text might contain legitimate accented characters, symbols or mixed-language content. A transformation that fixes one word may damage another. Comparing alternatives is safer than silently replacing the entire document with a single guess.

Can this tool fix every character-encoding error?

No. This tool focuses on common Western cases involving UTF-8 text misread as Windows-1252 or ISO-8859-1. Some older East Asian encoding mistakes require different methods. If the source has already replaced unknown characters with ordinary question marks or replacement symbols, the lost information may no longer be recoverable.

Does the tool upload my text?

The transformations and candidate generation run in your browser. This page does not require a server-based repair API. Be mindful that other services, browser extensions or unrelated scripts on a website can have their own data-handling behavior.

Frequently asked questions

Why does my CSV or subtitle file contain strange symbols?

One possibility is that a program interpreted the file using the wrong character encoding. The same symptom can have other causes, so inspect the output and keep a copy of the original.

Will Unicode normalization repair mojibake?

Not by itself. NFC normalization combines canonically equivalent sequences, but it cannot generally reverse an incorrect byte-decoding operation. That is why normalization is an optional, separate step.

Can I use the tool with source code?

Yes, but compare results carefully. Even a seemingly harmless text transformation can change string literals, identifiers, comments or encoded data. Keep the original source and review all changes.

Can I repair a file that displays question marks instead of letters?

If the original character bytes have already been replaced with question marks, the missing characters cannot reliably be recovered from those question marks alone. Restore from an original or backup where possible.
