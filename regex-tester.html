How to use this regex tester

  1. Enter the expression without surrounding slash delimiters.
  2. Choose the flags, such as global matching and case-insensitive matching.
  3. Paste the text you want to inspect and run the test.
  4. Review the highlighted matches, indexes and capture groups.
  5. Optionally enable replacement preview, then copy or export results.

Understanding regex flags

  • g — Global: find multiple non-overlapping matches rather than only the first.
  • i — Ignore case: ignore case differences where the JavaScript engine allows.
  • m — Multiline: make ^ and $ recognize line boundaries.
  • s — Dot-all: allow . to match line terminators.
  • u — Unicode: enable Unicode-aware regex processing.
  • y — Sticky: match at the current lastIndex position rather than searching forward.

What are capture groups?

Parentheses can capture part of a match. Numbered capture groups are assigned from left to right, while named groups label the captured values. For example, (?<year>\d{4})-(?<month>\d{2}) creates named captures for a four-digit year and a two-digit month.

Testing a pattern is not the same as validating the data

A regex can check whether a date string resembles 2026-10-17 without confirming that every matched date is a real calendar date. Similar limits apply to email addresses, URLs and phone numbers. Use a domain-specific validator when the actual value must be correct.

Why the tool has a timeout

Some regex patterns can take a long time on certain input strings. This tool runs matching in a separate temporary Web Worker and stops it after a time limit. That reduces the risk of a slow pattern freezing the page, but it does not guarantee that every expression is safe or fast.

JavaScript syntax versus other regex engines

This tester uses your browser's JavaScript RegExp engine. Patterns written for Python, PCRE, Java, .NET, Ruby or other engines may behave differently. If your production code uses another engine, test the expression in a tool that supports that particular flavor.

Frequently asked questions

Why is only one match shown?

Without the global flag g, JavaScript matching typically stops after the first result. Enable the flag when you want all non-overlapping matches.

Does this tool upload my pattern or sample text?

The matching is performed in a browser Web Worker. No server-based regex service is required. Avoid entering sensitive production data on websites unless you understand the entire site's data handling.

Does this regex tester guarantee that my pattern is secure?

No. A successful test only shows how the chosen pattern behaves on the supplied sample. It is not a formal ReDoS security audit or proof that a pattern will be efficient for every input.

Can I export the matches?

Yes. You can copy the match list or download a CSV containing match indexes, matched text, and capture-group details for the entries shown by the tool.
